# Диаграммы

В разделе представлены диаграммы, подготовленные в рамках анализа и проектирования решения:

- BPMN AS-IS — текущий процесс работы менеджера на выставке;
- BPMN TO-BE — целевой процесс после внедрения мобильного решения;
- Use Case Diagram — основные пользовательские сценарии;
- UML Class Diagram — основные сущности предметной области и связи между ними.
