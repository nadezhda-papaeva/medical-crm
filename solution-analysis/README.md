# Анализ вариантов решения

В рамках проекта рассматривались готовые CRM и мобильные решения, потенциально соответствующие требованиям бизнеса.

Основные критерии сравнения:

- скорость поиска клиента;
- работа с мобильного устройства;
- офлайн-режим;
- возможность работы с существующей клиентской базой;
- создание и изменение карточек клиентов;
- синхронизация данных;
- работа с маркетинговыми материалами;
- сложность внедрения;
- необходимость доработок.

Часть информации о поставщиках и коммерческих условиях не публикуется в целях сохранения конфиденциальности.
