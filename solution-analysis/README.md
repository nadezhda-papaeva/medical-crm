# Анализ вариантов решения

В рамках проекта рассматривались готовые CRM-системы, мобильные решения и специализированные продукты, которые потенциально могли закрыть потребности менеджеров во время профильных выставок.

Основной задачей анализа было определить, можно ли реализовать необходимый сценарий на базе готового решения или потребуется дополнительная настройка либо разработка.

## Ключевые критерии оценки

При сравнении решений учитывались:

- наличие мобильного приложения;
- возможность работы без интернет-соединения;
- локальный доступ к клиентской базе;
- поиск клиента по нескольким параметрам;
- скорость поиска;
- просмотр и изменение карточки клиента;
- создание нового клиента;
- добавление комментария;
- последующая синхронизация данных;
- работа с маркетинговыми материалами;
- возможность отправки клиенту ссылки на материалы;
- сложность внедрения и необходимость доработок.

## Рассматриваемые варианты

В рамках анализа изучались:

- BPMSoft;
- ST-Mobi;
- мобильные решения на базе 1С;
- amoCRM;
- ConfControl;
- LeadFrog;
- другие варианты реализации мобильного доступа к клиентской базе.

Для части решений потребовалось дополнительное взаимодействие с поставщиками, поскольку наличие отдельных функций нельзя было однозначно определить по открытой документации.

## Подход к сравнению

По каждому варианту оценивалось:

1. закрывает ли решение требования MVP в готовом виде;
2. какие функции требуют настройки;
3. какие требования потребуют доработки;
4. какие ограничения существуют у мобильной версии;
5. поддерживается ли полноценная работа офлайн;
6. каким образом выполняется синхронизация данных;
7. можно ли реализовать работу с маркетинговыми материалами.

## Результат анализа

Анализ показал, что критичным фактором является не просто наличие мобильного приложения, а возможность выполнить основной пользовательский сценарий при отсутствии стабильного интернет-соединения.

Поэтому решения, в которых мобильный интерфейс фактически зависит от постоянного доступа к серверу, требуют дополнительной проверки или доработки.

Отдельно анализировался сценарий работы с маркетинговыми материалами: из-за большого объёма файлов хранение полного комплекта материалов непосредственно на мобильном устройстве не рассматривалось как обязательное требование. В офлайн-режиме менеджеру достаточно выбрать необходимые материалы, а отправка ссылки может выполняться после восстановления соединения.
